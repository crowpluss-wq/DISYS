# 인스타그램 카드뉴스 시각 배치 가이드 (제거 vs 강화 대비 구조)

## 디자인 시스템
- **강화(Empower)**: #FF4B5C (메인 강조 컬러, 중요 수치 및 문구 적용)
- **제거(Remove)**: Grey (#808080) - 불필요한 요소 시각적 제거 처리
- **폰트**: 주요 데이터 포인트 28pt 이상 확대 배치 (모바일 가독성 최우선)

## 레이아웃 구조 (2분할 수직 대비형)
| 영역 | 디자인 규칙 | 비고 |
| :--- | :--- | :--- |
| **좌측(제거)** | Grey 처리 및 삭제 아이콘 적용, 텍스트 최소화 | "불필요한 특약 제거" 강조 |
| **우측(강화)** | #FF4B5C 컬러 포인트 사용, 비교 수치 강조 | "실질적 보장 강화" 대비형 메시지 배치 |

## 채널별 비주얼 자산 매핑
1. **메인 카드 뉴스**: 2분할 대비표 (한쪽은 회색 제거 처리 / 다른 쪽은 강렬한 #FF4B5C 포인트)
2. **비교 테이블 세부**: 각 보험사의 핵심 수치(가입자 체감가 등)를 대조표 형태로 배치
3. **인스타그램 후크용 비주얼**: 1번후크를 메인으로 한 대비형 인포그래픽 레이아웃 |
