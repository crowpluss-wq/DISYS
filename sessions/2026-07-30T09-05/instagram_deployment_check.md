# 인스타그램 채널 최적화 및 트래킹 통합 검증

## 1. 후크(Hook) 구성 검토 (신뢰형 / 자극형)
- **공통**: 모든 문구에 트래킹 코드 G-1234567890 포함 여부 전수 확인.
- **신뢰형**: 보험 비교 보고서의 "제거/강화" 대비가 명확한지, 텍스트가 신중하고 정보성인지 검증.
- **자극형**: 후크가 강렬하지만 정확하며 가시적인 수치 개선을 강조하는지 확인 (10-14 의사결정 반영).

## 2. 시각적 일관성 매칭
Designer의 세로분할 카드뉴스 디자인(제거: #808080 / 강화: #FF4B5C)과 문구 대비 구조가 정확히 대응하는지 검증.

## 3. 채널별 게시 전략 (오전/오후 페르소나)**
- **오전**: 정보성 성격에 맞는 신뢰형 후크 배포 패키지 구성.
- **오후**: 관계성 기반의 자극형 문구로 인게이지먼트 극대화.

## 4. 최종 검증 완료 사항**
[ ] 트래킹 코드 G-1234567890 모든 버전 삽입 확인
[ ] 제거/강화 대비 구조(한 페이지 비교) 일관성 확보
[ ] 채널별 최적화된 후크 세트 1~2종 포함 완료

## 배포 패키지 구성 (할당)**
- **수행 에이전트**: 인스타그램 콘텐츠 최종 검증 및 트래킹 코드 매핑.
- **목표**: 모든 배포용 문구가 정확하며 추적 가능하고 가독성이 높은(최소 28pt 수준) 상태를 보장함.

## 후속 조치**
검증 완료 시 각 세트의 게시 예정 시간과 인스타그램 스토리 아이디어 1개를 추가 생성한다.
