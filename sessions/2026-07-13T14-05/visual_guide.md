# 카드뉴스 디자인 가이드 (한화 대비 구조 기반)

## 1. 레이아웃 원칙
*   **세로형 2분할**: 화면을 수평으로 반분하여 왼쪽(제거)과 오른쪽(강화)의 극명한 시각적 대조를 형성함.
*   **시선 유도**: 왼쪽에서 우측 방향으로 이동하며 '불필요한 것'이 삭제되고 '실질적인 보장'이 강화되는 서사 제공.

## 2. 컬러 및 타이포그래피
*   **제거(Remove) 영역**: #808080 (Grey). 가독성을 낮추고 시선을 오른쪽으로 흘림. 주요 수치는 크기 축소.
*   **강화(Strengthen) 영역**: #FF4B5C (**핵심 브랜드 컬러**). 선명한 대비를 통해 가장 중요한 보장 항목을 강조함. 핵심 비교 지표는 **28pt 이상 확대**.

## 3. 인스타그램 콘텐츠 매핑 (두 트랙)*
*   **오전(정보형)**: 세분화된 보험 가입 정보를 정확하고 신뢰할 수 있게 배치.
*   **오후(관계형)**: 개인의 상황에 맞는 맞춤형 보장을 시각적으로 부각시켜 감성적 연결 강화

## 4. 디자인 요소 적용 규칙
- 제거 항목에는 [X] 아이콘이나 '삭제' 태그를 회색으로 처리할 것 (130755 결정사항 준수).
- 강조 포인트에만 #FF4B5C 컬러 사용 제한하여 가독성과 강도 극대화.
