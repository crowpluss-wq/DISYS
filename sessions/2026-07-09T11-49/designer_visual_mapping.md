# 인스타그램 카드뉴스 시각 매핑 (제거 vs 강화 대비 구조)

## 디자인 원칙
- **메인 컬러**: #FF4B5C (강화), Gray (#808080, 제거 영역 표시용)
- **레이아웃**: 세로형 2분할 (좌: 제거/회색 처리 및 삭제 아이콘 | 우: 강화된 핵심 보호 강조)

## 대비 구조 매핑 ([reports/insurance_comparison_matrix_final.md] 기반)
| 항목 | 상태 | 시각적 연출 지침 |
| :--- | :--- | :--- |
| 불필요한 중복 특약 | 제거 (Grey) | 회색 처리, 삭제 아이콘(--X--) 표기 및 배경을 흐릿하게(Blur) 처리하여 제외 강조 |
| 핵심 보호 영역 | 강화 (#FF4B5C) | 28pt 이상 대형 폰트 사용, 대비 컬러(#FF4B5C)로 하이라이트, 수치 가독성 확보 |

## 배포 패키지 구성 요소
1. 카드뉴스 소스: 위 매핑을 적용한 인스타그램용 비교표 이미지 세트 (제거/강화 대조 구조 반영)
2. 디자인 가이드라인: 제거 아이콘 위치 및 강화 컬러 코드 사양 포함
3. 콘텐츠:** Writer의 대비형 후크 5종 세트를 하단에 배치(Designer 시각 정보와 일치하도록)**

## 추가 사항
- 수치는 최소 28pt 이상으로 확대하여 모바일에서도 즉시 확인 가능하게 할 것
- 인스타그램 채널 업로드 시간: 오전 9:00 및 오후 6:30 (의사결정 이력 준수)
