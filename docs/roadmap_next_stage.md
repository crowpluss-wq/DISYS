# 보험 상품 비교 콘텐츠 가공 계획

## 현황 진단
- **데이터**: 20개사 보장 대비 구조(제거·강화 프레임워크) 정립 완료 (코다리, Researcher 검증됨)
- **이미진** 카드뉴스용 비주얼 패키지 기획안 존재하나 인스타 채널별 배포 전략 미확정
- **한계**: 원시 비교 데이터 그대로는 일반인이 아닌 보험 전문가 아니면 읽기 어려움 → 가공 필요

## 제안: 콘텐츠 3종 세트로 분화
1. **블로그용 심층 보고서 (Deep Dive)**
   - 대상: '보험은 복잡해서 못 고르겠다'는 정보 갈증 청자
   - 내용: 내 보험 다보아 앱과 기존 설계의 실질 비용 차이 수치적 비교 + 중복 특약 정리 가이드
   - 목표: 인스타/유튜브 시청자의 블로그 유입 (롱테일 SEO)

2. **인스타그램 카드뉴스 시리즈 (Visual Digest)**
   - 채널별 최적화 배포로 효율 극대화
   - 세트 3종 구성:
     1. [공격형] "당신 보험에 불필요한 특약만 O원씩 매달려있다면?" (자극적 진단)
     2. [정보형] 내보험다보아 앱으로 중복금액 한눈에 찾기 (도구 중심)
     3. [결과형/증명용] 기존 고객들의 실제 보험료 절감 사례 나열

3. **쇼트 영상대본 세트**
   - 인스타 릴스 / 유튜브 쇼츠
   - 구조: 1분 미만, 핵심 메시지 단 하나에 집중 ("이거도 안 지울 거면 돈 버리고 있는 거예요")

## 협업 배분 (예상)
- **Writer**: 블로그용 상세 비교 보고서 작성 (데이터 기반 사실 주장 강화)
- **Instagram**: 카드뉴스 3종 디자인·문구 세트 제작, 인스타 피크타임별 테스트 배포
- **Leo**: 쇼츠 대본 생성 및 채널별 최적 시간대 배치

## 기대 효과
단순 '보험 비교'를 넘어 사용자 가치 기반의 콘텐츠로 재가공하면 전환율 개선 가능.
