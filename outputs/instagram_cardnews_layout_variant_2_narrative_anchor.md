# 인스타그램 카드뉴스 시각화 가이드 (변형 2: 메시지 요약 강조)

## 디자인 원칙
- **제거(Grey)**: `#808080` - 불필요한 항목을 회색처리하여 배경으로 후퇴시키고 핵심 강화 내용만 선명하게 유지
- **강화(Red)**: `#FF4B5C` - 비교표 내 강조 포인트와 하단 요약 문구에 일관성 있게 적용

## 레이아웃 세부사항
1. **대비 매트릭스**: 제거/강화 구조를 2분할 대비형으로 구성하되, 강화 항목(Red)의 시인성을 제어항보다 한 단계 더 높임 (굵기 가중치 및 테두리 효과 활용)
2. **수치 강조**: 주요 보장 내용과 보험료 절감 수치를 확대 배치하고 비교 대상간 차이를 숫자로 명시
3. **하단 요약 섹션**: 카드뉴스 최하단을 전용 공간으로 할당하여 "불필요한 지출 대신 확실한 보호를 선택하세요" 등의 한 문자 핵심 메시지를 강조 배정

## 자산 사양
- 주요 수치 확대 레이아웃 위치: [45,73], [120,48] (수치는 가로/세로 좌표 기반)
- 대비 컬러 코드 고정: 제거 #808080 / 강화 #FF4B5C
