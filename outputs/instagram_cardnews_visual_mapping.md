# 인스타그램 카드뉴스 시각 매핑 정보 (제거 vs 강화 대비)

## 디자인 원칙
- **비교 구조**: 2분할 레이아웃 — 왼쪽 '불필요한 특약 제거', 오른쪽 '실질적 보장 강화'
- **컬러 시스템**: 제거 영역 = #808080(Grey), 강화 영역 = #FF4B5C
- **시각 효과**: 제거 항목에는 [삭제 아이콘]과 회색 처리 적용

## 레이아웃 매핑 정보
| 구분 | 디자인 요소 | 시각적 강조 포인트 |
| :--- | :--- | :--- |
| **제거(Remove)** | #808080 + 삭제 아이콘 | 불필요·중복 특약을 제거하여 보험료 절감 효과 부각 |
| **강화(Enhance)** | #FF4B5C (메인 컬러) | 실질적 보호를 위한 보장 한도 현실화 및 핵심 내용 집중 강화 |

## 카드뉴스 시안 구조
1. **표지**: "내 보험, 제대로 지키고 있나요?" (대비 레이아웃 예고)
2. **비교 페이지**: 왼쪽(Grey/삭제 아이콘 - 불필요 특약 제거), 오른쪽(#FF4B5C - 맞춤형 보장 강화) 대비 배치
3. **핵심 메시지**: "불합리은 덜어내고, 당신의 내일을 위한 꼭 필요한 보호만 키웁니다"

## 참고 레퍼런스 (가이드 기반)
- [제거] → 불필요한 항목 삭제를 시각적으로 한눈에 대비시키는 디자인 |
- [강화] → 강렬한 `#FF4B5C` 컬러로 실질적 보장 강화 강조
