# [최종] 보험 비교 분석 및 인스타그램 홍보 패키지

## 1. 핵심 메시지 (제거 vs 강화 대비 구조)
- **비교 기준**: 불필요한 고정비성 특약(Grey) → 맞춤형 보장 강화(Red)
- **핵심 문구**: "불필요한 것은 제로(Grey), 진짜 필요한 보장은 강화(Red)"

## 2. 인스타그램 배포용 후크 세트 (5종)
1. **직설적 경고형**: 매달 나가는 보험료, 정말 다 보호받는 데 쓰이고 있나요? 불합리 제거하고 강화에 집중한 한화 대비 구조 확인해보세요.
2. **비교 강조형**: [제거 vs 강화] 복잡한 특약 대신 당신에게 꼭 맞는 보장만 남겼습니다. 진짜 필요한 것만 골라보세요.
3. **가성비 소구형**: 보험료의 거품을 걷어내고, 실질적인 보호를 위해 강화를 택했습니다. 스마트한 가입자의 선택.
4. **전문가 제언형**: 시중 보험사의 불필요한 특약을 제거하고 강화된 보장 구조로 최적화 — 당신을 위한 맞춤 설계.
5. **궁금증 유발형**: 보험 계약서의 복잡함에 속고 계신가요? 우리가 준비한 '제거 vs 강화' 비교표를 확인하세요.

## 3. 배포 매칭 정보 (각 후크별 카드뉴스 & 캡션)
- 각 후크는 Designer 패키지의 대비 레이아웃(grey/#808080, red/#FF4B5C)과 일관된 비주얼을 사용하며, 하단에는 한 문장 요약 배지를 포함한 캡션을 동반합니다.

## 4. 게시 전략
- **권장 시간**: 오후 7시 - 9시 (직장인 세그먼트 집중 노출)
- **스토리 아이디어**: 카드뉴스 첫 페이지에서 '제거/강화' 투표 실시 및 하이라이트로 고정된 상세 비교표 링크 연결.
