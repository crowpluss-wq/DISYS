# 인스타그램 배포 콘텐츠 패키지 (최종)

## 🎯 선정된 후크: 제1안 (진단비 강화 및 불필요 특약 제거 대비형)
- **선정 이유:** 우리 브랜드 정체성인 "제거(grey)"와 "강화(red)"의 시각적/메시지 구조가 가장 선명하게 녹아있고, 인스타그램 카드뉴스 레이아웃과 1:1 매칭되어 즉시 배포 가능한 베스트 옵션임.

## 📋 콘텐츠 구성
### [카드뉴스 비주얼 가이드]
- **레이아웃:** 2분할 세로형 (좌/우 대비 구조)
- **컬러 코드:** 제거(grey #808080), 강화(red #FF4B5C) 고정
- **텍스트 배치:** 핵심 수치는 최소 28pt 이상으로 확대, 하단에 한 문장 요약

### [캡션 세트]
1.  **직구형**: 매달 나가는 보험료, 진짜 당신을 보호하는 데 쓰이고 있나요? 불필요한 특약을 제거하고 강화된 보장에 집중해야 하는 이유를 카드뉴스로 확인해보세요. #보험제안 #진단비강화

2.  **스토리텔링**: 남들이 다 가입한다고 가입할 때, 우리는 '어떤 걸 걷어내고 무엇을 채워야 진짜 좋은 보험인지'부터 따집니다. (그림에서 제거vs강화 대비를 확인하세요) #보험재설계 #제거와강화

3.  **정보형**: [비교표] 시중의 복잡한 특약들을 걷어내고 강화된 보장 구조로 대체할 때, 가입자 체감형의 최적진 상품이 완성됩니다.
4.  **공감유도**: 보험이라는 고정비에 매달리기 전에 한 번만 비교해보세요. 제거와 강화를 통해 시각적으로 드러나는 차이가 바로 당신의 돈을 아끼는 구조입니다.

5.  **체험형(질문)**: 좋은 보험이 필요한데 어디서부터 시작할지 막막하다면? 카드뉴스를 넘겨보며 제자리에 앉은 비교표 하나로 한눈에 정리해드립니다.
