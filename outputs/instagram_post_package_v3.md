## 인스타그램 채널별 홍보 후크 5종 (배포용)

각후는 블로그의 '제거 vs 강화' 대비 구조와 일관되게 설계되었습니다.

### 유형별 후크 구성:
1. **[호기심형]** "매달 나가는 보험료, 정말 다 보호받는 데 쓰이고 있나요? 불합리 제거하고 강화에 필요한 것에 집중한 한화 대비 구조 확인해보세요." → 블로그의 전체 메시지를 직관적으로 압축한 핵심 후크입니다.
2. **[제거 중심]** "아직도 중복 진단비 때문에 보험료 낭비하시나요? 불필요 특약 제거로 지출은 줄이고 보장은 강화했습니다." → '제거(Grey)' 대비 구조의 장점을 부각한 유형입니다.
3. **[강화 중심]** "당신에게 진짜 필요한 보호만 남기고 나머지는 다 삭제합니다. 한화 대비 강진보장(강화)을 확인하세요." → '#FF4B5C' 강화 부분을 전면에 내세운 후크입니다.
4. **[비교형]** "어떤 보험이 더 나은지 고민된다면? 제거vs강화 표 하나로 비교 끝내고 최적의 구조를 선택하십시오." → 카드뉴스 시각 대비와 동기화된 직관적인 비교 유형입니다.
5. **[해결 제안型]** "복잡한 한글 대신 명확한 대비구조로 결정하십시오. 불필요는 제거, 필요한 것은 강화 — 바로 쓰는 맞춤형 보장제안" → 블로그 보고서의 결론을 기반으로 배포 즉시 활용 가능한 세트입니다.
