# [마스터 배포 패키지] 보험 비교 분석 및 인스타그램 캠페인 가이드

## 1. 핵심 비교 매트릭스 (제거 vs 강화)
- **비교 구조**: 불필요하거나 한계가 있는 기존 항목은 제거(#808080), 실질적 보장(진단비·수술비 등)이 강화된 내용은 강화(#FF4B5C).
- **시각화 원칙**: 핵심 비교 수치는 모바일 가독성을 위해 28pt 이상으로 크게 표기.

## 2. 인스타그램 배포 세트 (두 트랙 후크)
| 구분 | 오전: 정보형 (Educational Track) | 오후: 감성형 (Emotional Track) |
| --- | --- | --- |
| **후크** | "아직도 보험 한도를 고민하시나요? 팩트로 비교해 드립니다." | "나를 위한 진짜 보장, 당신의 내일을 강화하세요." |

## 3. 채널별 배너 및 홍보 문구 (한화 대비 구조)
- 모든 이미지 하단에 단일 GA4 추적 코드 포함: G-1234567890
- 제거/강화 시각 언어 통일 적용 (제거 #808080 / 강화 #FF4B5C)

## 4. 핵심 메시지 일관성 검증 결과
- 비교 보고서와 블로그 원고 간의 진단비·수술비 강조 포인트 동일 확인 완료.
