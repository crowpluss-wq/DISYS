# [배포용 최종 패키지] 불필요한 특약 대신 진단·수술 강화 (deployment_ready)

## 📌 인스타그램 배포 전략 개요
- **오전 세트**: 정보형 / 직설 — "보험료가 비싸다고 느껴진다면? 당신이 내고 있는 불필요한 특약들이 범인이었습니다."
- **오후 세트**: 관계형 / 공감 — "부모님 보험, 늘 똑같은데 매달제 돈만 나가는 것 같아 답답하셨죠?"

## ⚖️ 핵심 대비 구조 (가독성 최적화)
* 모든 비교 수치는 가독성을 위해 최소 **18pt** 이상 유지 (코더 검증 완료).
- 제거 (Gray / #808080): 중복·불필요 항목 삭제 → 보험료 절감
- 강화 (Red / #FF4B5C): 진단비 · 수술비 한도 확대 → 보호 강화

## ⏰ 채널별 피크타임 배포 일정
| 구분 | 오전 세트 (정보형) | 오후 세트 (관계형) |
| :--- | :--- | :--- |
| 인스타그램 피드 | **08:30** (데일리 뉴스 소비 타임) | **19:45** (저녁 시간 관계 형성 강화) |

- 본문: 제거(gray)/강화(red) 대비 구조를 카드뉴스로 한눈에 확인하세요.
