# 카드뉴스 시각화 레이아웃 가이드: [제거 vs 강화] 대비 구조

## 1. 비주얼 시스템 (Visual System)
- **그레이존(Grey Zone)**: #808080 | 제거 대상 항목에 적용, 낮은 채도로 불필요한 요소 표현
- **강조존(Power Zone)**: #FF4B5C | 강화 모델에 적용, 고채도 대비로 보호 수준 시각적 강조

## 2. 레이아웃 사양 (Layout Specification)
- **포맷**: 세로형 1080x1920 비율의 모바일 최적화 카드뉴스
- **구조**: 상/하(또는 좌/우) 수직 2분할 구조

## 3. 영역별 시각 요소 (Segmental Visual Elements)
### [제거] 세그먼트
- 아이콘: 🚫 삭제 마크 (회색 처리)
- 레이아웃 좌표: 상단부 / 50% 면적
- 비주얼 가이드: 중복 특약 및 불필요한 항목들, 회색처리된 텍스트와 비교표 배치

### [강화] 세그먼트
- 아이콘: ✅ 강화 마크 (엠베드 포인트)
- 레이아웃 좌표: 하단부 / 50% 면적
- 비주얼 가이드: 진단·수술비 등 보호 기능 강화 영역, 강조 컬러(#FF4B5C), 시각적으로 우세한 대비 효과
