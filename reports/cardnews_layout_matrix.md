# 카드뉴스 디자인 브리프: 제거/강화 대비 시각 매트릭스

## 한눈에 들어오는 대조 구조
복잡한 보험 문구를 두 영역으로 분할하여 '불필요함'과 '보장 강화'의 질적 차이를 직관적으로 전달하는 세로형 2분할 레이아웃입니다.

## 디자인 사양 및 가이드라인

### 컬러 팔레트
- **제거(Remove)**: #808080 - 불필요한 특약을 회색으로 처리하고 삭제 아이콘을 병기합니다.
- **강화**: #FF4B5C - 강화된 보장 항목에는 강조용 빨간색을 적용하여 한눈에 대비됩니다.

### 타이포그래피 및 레이아웃
- **헤드라인**: 28pt 이상, 강력하고 읽기 쉬운 볼드체로 설정합니다.
- **본문/수치 정보**: 18pt까지 확대하여 시인성을 높입니다.
- **시각 매트릭스**: 기존의 줄글 형태를 대신하며 제거와 강화의 대비 구조가 한눈에 들어오는 세로형 비교표 레이아웃을 사용합니다.

### 배포 패키지 요건
- **이미지 생성**: 디자인 가이드(reports/final_visual_design_guide.md)에 명시된 수치를 바탕으로 실제 카드뉴스 이미지 파일들을 생산해야 합니다.
- **인스타그램용 콘텐츠 세트**: 정보형과 관계형을 아우르는 두 트랙의 배포 패키지를 유지하십시오.

## 비교 매트릭스 요약 (내부 참고)

| 항목 | 대비 구조 및 시각 효과 | 강조 컬러 코드 |
| :--- | :--- | :--- |
| 불필요 특약 제거 | 회색 처리 + 삭제 아이콘 적용 | `#808080` |
| 강화된 보장 내용 | 핵심 가치 부가로 한데 묶어 시각화 | `#FF4B5C` |

## 배포 정보 업데이트 (distribution_package.md 반영 사항)
- 인스타그램용 디자인 소스 패키지의 최신 버전을 활용하십시오
- 각 채널별 문구(정보형/관계형) 세트를 distribution_package.md에 포함한 상태로 유지하며 자동화 체크리스트를 통해 배포 준비 완료를 확인하십시오
