# 제거 vs 강화 대비 구조 (카드뉴스용)

| 구분 | 기존 보험 [제거 - #808080] | 새로운 설계 [강화 - #FF4B5C] | 비고 |
| :--- | :--- | :--- | :--- |
| 진단비 한도 | 1,000만원 이하의 불필요한 소액성 항목 통합 제거 | **진단 및 수술비 집중 강화** (대형 질병 보장 확대) | 핵심 차별화 포인트 |
| 입원 일당 | 중복된/실효 없는 특약 제외 | 실제 체감 가능한 치료 중심 한도 현실화 | 가입자 체감 증대 |
| 보험료 최적화 | 제거를 통한 불필요한 거품 삭제 | **보장 강화 및 구조 개선으로 실질 비용 절감** | 핵심 메시지 유지 |

## 시각 레이아웃 지침 (세로형 2분할)
- 왼쪽: '#808080' 회색 처리된 제거 항목들 — '불필요한 거품 삭제' 강조
- 오른쪽: '#FF4B5C' 강화 컬러의 새로운 설계 — '체감하는 보장 확대' 시각화
- 모든 수치 정보는 가독성을 위해 최소 18pt 이상의 글꼴 크기로 표시

## 배포용 시각 디자인 가이드
- **제거(Grey)** vs **강화(#FF4B5C)** 대비를 통해 고객이 체감하는 보험의 질적 차이를 직관적으로 전달합니다.
