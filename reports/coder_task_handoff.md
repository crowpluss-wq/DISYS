# 🛠️ 코다리: 카드뉴스 이미지 생성 태스크 가이드

Designer가 확정한 대비 구조와 레이아웃 사양을 기반으로 실제 배포용 카드뉴스 세트를 생산하십시오. 이미 디자인사양이 모두 정의되어 있으므로 추가적인 시각적 수정 없이 아래 지침만 따르면 됩니다.

## 🎨 시각 요소 명세
- **구조**: 세로형 2분할 (좌: 제거 #808080 / 우: 강화 #FF4B5C)
- **제거(REMOVE)**: 회색 (#808080), 삭제 아이콘 표기, 불필요한 항목들은 시각적 대비를 위해 회색 처리
- **강화(ENHANCE)**: 강조 레드 (#FF4B5C), 핵심 보장은 18pt 이상 확대 및 강화 아이콘 동반

## ✅ 작업 요구사항
Designer가 확정한 [latest] 비교 매트릭스를 카드뉴스 소스로 활용하십시오. 모든 수치와 금액이 최소 18pt 가독성을 충족하도록 생성해야 합니다. 한 페이지 분량의 모바일 최적화 세트를 완성시키십시오.

**준비 완료**. 코다리가 실제 이미지 파일을 생산할 때 Designer가 설계한 대비 구조를 정확히 반영하면 배포 준비 상태(deployment_ready)로 전환됩니다.
