# 카드뉴스 레이아웃 소스 (제거 vs 강화 대비 구조)

## 디자인 컨셉
- **레이아웃**: 세로형 2분할 (Vertical Split Layout). 모바일 스크롤 환경에서 두 영역을 시각적으로 즉시 대조함.
- **대비 체계**:
  - **REMOVE (제거)**: `#808080` 회색 처리 + 삭제 아이콘 → 중복/불필요한 특약 제거 강조.
  - **ENHANCE (강화)**: `#FF4B5C` 포인트 컬러(28pt 이상 확대) 및 명확한 대비 강화.

## 비주얼 가이드라인
1. **상단부**: 핵심 비교 항목을 표 형태로 시각적 대조 구조로 배치.
2. **제거 구간**: 회색 텍스트와 삭제 아이콘으로 처리하여 '덜어냄'의 의미 전달.
3. **강화 포인트**: 강화 대상 요소에 `#FF4B5C`를 적용하고, 수치는 가독성을 위해 크기 확대(28pt+).
4. **배경 및 타이포**: 깔끔한 백색 배경에 대비가 선명히 드러나는 산세리프 체 사용.

## 픽스 세트 (Reference)**
- [1] 제거 아이콘 에셋 (#808080)
- [2] 강화용 강조 태그 (`color: #FF4B5C; font-size: larger`)
