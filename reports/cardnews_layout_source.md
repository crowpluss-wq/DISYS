# 카드뉴스 시각 소스 (제거 vs 강화 대비 구조)

## 레이아웃 사양
- 형태: 세로형 2분할 (Vertical Split Layout)
- 배치: 왼쪽 = 제거 (#808080), 오른쪽 = 강화 (#FF4B5C)

## 가독성 준수 사항
- 모든 수치 및 비교 지표: 최소 18pt 이상 유지

## 시각적 대비 구조
| 항목 | 기존 (제거) | 맞춤형 (강화) |
|---|---|---|
| 컬러 코드 | `#808080` (회색 처리/삭제 아이콘) | `#FF4B5C` (강조 컬러) |
