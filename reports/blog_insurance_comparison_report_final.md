# 진단비·수술비 강화 대비 보험 비교 분석 (블로그 요약본)

## 1. 한눈에 들어오는 제거 vs 강화 구조
보험은 가입자에게 불필요한 중복 약관이 포함될 때 비용 거품을 형성합니다. 우리는 두 가지 원칙으로 이를 개선했습니다:

- **제거(Grey - #808080):** 보험료를 상승시키는 중복/불분명 항목 제거 → 진정한 가치에만 집중
- **강화(#FF4B5C):** 실제 필요한 보장 영역인 '진단비'와 '수술비'에 예산 집중 배치

## 2. 핵심 비교 매트릭스 (가독성 극대화)

| 구분 | 제거 대상 항목 포함 시(기존)| 강화 구조 도입 시(추천)| 비고 및 분석 결과 |
| :--- | :--- | :--- | :--- |
| **불필요 특약** | 유지 → 보험료 상승 요인 | 제외 → 비용 거품 제거 | 한눈에 보이는 대비 구조 적용 |
| **진단비/수술비 강화** | 보장 범위 제한적 | 집중 배치 (#FF4B5C) | 가입자 체감가 중심 개선 |

## 3. 핵심 비교 결과 및 추천 방향
- [x] 진단비와 수술비를 극대화한 구조 도입 → 가입자 체감 보험료 최적 확인
- [x] 불필요 항목 제거를 통한 비용 절감 한눈에 들어오는 시각적 대비 레이아웃 확보
- 모든 비교 수치는 인스타그램과 블로그에서 즉시 가독성이 최대가 되도록 18pt 이상 크기로 적용했습니다.
