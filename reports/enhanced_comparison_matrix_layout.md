# 보험 비교 시각 매트릭스 레이아웃 (Designer v2026-07-11)

## 핵심 디자인 원칙
- **제거(Grey)**: 불필요한 특약과 높은 비용을 회색 처리(#808080). 제거 아이콘 적용.
- **강화(Red)**: 실질적인 보장 강화 부분을 강조색(#FF4B5C)으로 표현.
- **가독성**: 핵심 수치는 28pt 이상 확대, 나머지 정보는 18pt 단일화.

## 레이아웃 구조 (세로형 2분할)
| 영역 | 디자인 사양 및 시각 요소 |
| :--- | :--- |
| 상단 헤드라인 | **"불필요한 비용은 제거하고, 당신을 위한 보장은 강화하십시오"** (Bold/Red 강조) |
| 좌측 패널 (제거) | 회색 배경 (#808080), 삭제 아이콘 표기. 제거된 특약 리스트 나열. |
| 우측 패널 (강화) | 흰 배경, 포인트 컬러(#FF4B5C). 강화된 보장 내용 강조 처리. |
| 하단 요약 | 한 문장의 핵심 메시지 배치 및 문의 유도(CTA) |

## 배포 정보 업데이트
- 인스타그램용 2분할 카드뉴스 이미지 제작 시 위 대비 구조 일관 적용.
