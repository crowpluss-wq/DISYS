# 인스타그램 카드뉴스 배포용 시각 소스 패키지 (최종 검증 완료)

## 디자인 구조
- **레이아웃**: 세로형 2분할 대비 레이아웃
- **제거(REMOVE)**: `#808080` 회색 처리 및 삭제 아이콘 표기 → 불필요한 중복 보험료 제거 강조
- **강화(STRENGTHEN)**: `#FF4B5C` 강화 컬러 적용 → 진단/수술비 등 핵심 보호 영역 강화

## 가독성 표준
- 모든 수치 글꼴 크기 최소 18pt 이상 고정 (모바일 최적화)

## 배포 패키지 구성 요소
[ ] 카드뉴스 시각 소스 파일 (제거vs강화 대비 구조 적용)
[ ] 인스타그램 채널별 두 트랙(오전 정보형/오후 관계형) 후크 세트 포함
