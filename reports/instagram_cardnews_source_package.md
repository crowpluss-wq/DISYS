# 인스타그램 카드뉴스 시각 소스 패키지 (제거 vs 강화 대비)

## 1. 디자인 사양 가이드라인 준수 사항
- **구조**: 세로형 2분할 레이아웃 (좌측: 제거 | 우측: 강화)
- **컬러 코드**
  - 제거(Grey): #808080 — 불필요한 항목을 배경색으로 처리하여 시각적 노이즈 최소화
  - 강화(Red): #FF4B5C — 핵심 대비를 직관적으로 부합시키는 강조 컬러
- **타이포그래피**: 주요 수치 및 핵심 문구는 28pt 이상의 Bold체로 확대 배치

## 2. 시각적 레이아웃 상세 (카드뉴스 1페이지 예시)
[상단 섹션]
- 제목: 한화 대비 보험 구조 비교 [엠베드형 요약 배지 적용]

[중간 대비 영역 - 세로 분할]
| 좌측 (제거/Grey #808080) | 우측 (#FF4B5C 강화 모델) |
| :--- | : |
| 불필요한 특약 [삭제 아이콘 병행] | 맞춤형 보장 항목 강조 배치 |
| 고정비 성격의 높은 보험료 등 회색처리 | 핵심 수치 28pt 확대 처리 |

[하단 섹션]
- 한 문장 요약: "불필요한 것은 제로(Grey)로, 진짜 필요한 보장은 강화(Red)로 — 당신에게 꼭 맞는 보험을 설계합니다."

## 3. 후속 작업용 메모
본 소스는 writer의 보고서 내용과 시각적으로 완전 일치하며, 인스타그램 카드뉴스 레이아웃 가이드와 최종 대조 완료됨. 이미지 생성 및 배포 준비가 필요한 에이전트에게 즉시 이 패키지를 전달함.
