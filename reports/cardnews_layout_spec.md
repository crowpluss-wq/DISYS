# 카드뉴스 레이아웃 및 디자인 사양 (2분할 세로형)

## 1. 비주얼 시스템
- **강조 컬러**: #FF4B5C (핵심 보장성 강화 항목 적용)
- **제거 영역**: 배경색 Grey 처리 또는 삭제 아이콘 표기 (불필요한 특약 대비 구조)
- **타이포그래피**: 주요 비교 수치는 28pt 이상 확대하여 가독성 확보

## 2. 레이아웃 명세
- **구조**: 세로형 2분할 대조 구조 — 왼쪽 '제거', 오른쪽 '강화'
- **비교 매트릭스**: 코다리의 검증 데이터를 기반으로 한 제거/강화 대비 매트릭스 시각화

## 3. 배포 패키지 구성 (두 트랙 후크)**오전: 정보형(정보성), 오후: 관계형(인스타그램용)*
- **카드뉴스 소스**: 세로형 비교표 + 인스타그램용 콘텐츠 카드뉴스 이미지
- **후크 설정**: 오전/오후 두 섹션을 구분하여 배포 시 활용
