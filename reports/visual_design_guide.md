# [디자인 가이드] 제거 vs 강화 대비 구조 시각화 (GA: G-1234567890)

## 1. 공통 비주얼 원칙
- **대비의 핵심**: '제거(#808080)'는 불필요한 거품과 중복을 지워내는 회색 처리로 시각화하고, '강화(#FF4B5C)'는 진실된 보호와 맞춤형 혜택을 강조 컬러로 부각합니다.
- **GA 트래킹**: 모든 제작 이미지의 하단 중앙에 단일 추적 코드 `G-1234567890`를 삽입하십시오.

## 2. 카드뉴스 세트 (모바일 최적화)
### 옵션 A: [제거 vs 강화] 비교형
- **레이아웃**: 상/하(또는 좌/우) 수직 분할, 한눈에 극명한 시각적 대조를 유도합니다.
- **제거 영역 (#808080)**: 중립적인 그레이톤 배경 + 스트라이크스루 아이콘 사용 → "불필요한 것은 지운다"는 메시지 전달.
- **강화 영역 (#FF4B5C)**: 강렬하고 따뜻한 강조 컬러 + 핵심 가치 아이콘 → 진실된 보호 강화 시각화.

### 옵션 B: [제거를 통한 강화] 스토리형 (인스타그램/유튜브용)
- **레이아웃**: 2분할 카드뉴스, '제거' 영역에서 제거 요소들을 회색 처리한 뒤 옆에 배치하고 '강화'로 바로 이어지는 레이아웃.
- **시각적 흐름**: 불필요함이 사라진 자리에 강화의 가치가 채워짐을 시선 이동으로 인지하게 유도합니다.

## 3. 채널별 대비형 배너 세트
### [A] 유튜브/블로그 상단용 (가로형)
- **레이아웃**: 좌측에 제거(회색 처리), 우측에 강화(강조 컬러)를 배치한 대조 구조입니다.
- **텍스트 위치**: 각 영역 중앙을 강조하되 하단 가장자리에 GA 추적 코드를 명확하게 표기하십시오.

### [B] 인스타그램/SNS 홍보용 (정방형)
- **레이아웃**: 상단을 제거, 하단을 강화로 분리한 2분할 구조를 적용합니다.
- **시각화 포인트**: 대비 효과 극대화를 위해 두 영역의 컬러 및 아이콘 유형을 명확하게 구분하십시오.

## 4. 디자인 코드를 활용한 시각 요소 매핑
[제거]에는 #808080과 중립적인 아이콘, [강화]에는 #FF4B5C와 강조성 아이코드를 적용하여 writer의 문구를 강화합니다.
