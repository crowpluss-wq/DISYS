# 최종 시각 자산 제작 가이드: 제거 vs 강화 대비 구조

## 1. 디자인 원칙 (제거 #808080 / 강화 #FF4B5C)
- **레이아웃:** 모바일 스크롤 환경을 위한 세로형 2분할 구조 적용.
- **강조 기법:** '제거'는 회색 처리와 삭제 아이콘 사용, '강화'는 브랜드 컬러(#FF4B5C) 및 주요 수치 확대(18pt 이상).
- **통합 트래킹 코드:** 모든 자산 하단에 G-1234567890 중복 없이 단 한 번만 삽입.

## 2. 카드뉴스 이미지 세트 (2종)
### [A] 비교 매트릭스형 - "불필요한 특약 제거 vs 실질적 가치 강화"
- **구조:** 좌/우(또는 상/하) 수직 분할 대비 배치
- **제거 구역 (#808080):** 복잡성·중복 항목 표기 후 삭제 아이콘 처리
- **강화 구역 (#FF4B5C):** 핵심 담보 강조 및 포인트 컬러 적용
### [B] 한눈에 보는 요약 - "당신의 보험, 이렇게 바뀝니다"
- **비교 대비:** 제거(제거해야 할 3가지) vs 강화(받아야 하는 3가지) 대조형 레이아웃

## 3. 채널별 대응형 배너 세트 (3종)
| 유형 | 주요 시각 포인트 | 배치 컨셉 |
| --- | --- | --- |
| **인스타그램용** | 제거/강화 대비 구조의 시각적 극대화 및 트래킹 코드 포함 | 인스타 카드뉴스 레이아웃 반영* |
| **네이버 블로그용** | '제거' vs 강화 핵심 비교 지표 가독성 확보(글자 확대) | 배너형 정보 요약 |
| **유튜브 쇼츠/숏폼** | 트래킹 코드 포함, 모바일 최적화 수직 2분할 강조 | 빠른 메시지 전달용 세로 배너 |

## 4. 자산별 배치 및 검증 사항
- [ ] 모든 카드뉴스 이미지 하단에 G-1234567890 중복 없이 삽입 확인
- [ ] 강화 포인트의 대비 컬러(#FF4B5C) 가독성 체크 (최소 18pt 이상 확대 적용 시각화)
- [ ] 제거 아이콘 및 회색 처리된 영역이 한눈에 구분되는지 검증
