# 보험 설계 비교 매트릭스 업데이트 (Researcher)

## 1. 분석 원칙 및 목표
- **제거(Grey):** 중복·불필요 특약 제외로 보험료 최적화
- **강화(#FF4B5C):** 진단비, 수술비 등 핵심 보장 강화
- **데이터 우선**: 확인된 정량적·제도적 정보만 사용

## 2. 한화 대비 주요 보험사 비교 매트릭스 (진행중)

| 구분 | 제1안: 제거(Grey) / 제2안: 강화(#FF4B5C) | 한화 대비 수준 (비교 대상) |
| :--- | :--- | :--- |
| **실손 의료비** | [ ] 최적화 vs [x] 진단/수술 강화 | ⬛ 비교 데이터 수집 및 매트릭스 업데이트 필요 ||

## 3. 상세 비교 사항 (데이터 검증 중)
- 한화 주요 상품(암, 실손 등)의 보장 범위 재검토
- 각 보험사별 특약 유무를 통한 장/단점 명문화
- 신규 보험 모델 포함 여부 및 가입 조건 정밀 확인
