# [디자인 사양] 2분할 세로형 대비 구조 가시성 최적화 (배포 준비용)

## 기본 시각 원칙
- **제거(Remove)**: 불합리한 특약 및 중복 항목 → 회색 처리(Grey), 취소선, 삭제 아이콘 활용.
- **강화(Strengthen)**: 진단·수술비 등 핵심 보장 → 강조색(#FF4B5C) 적용, 볼드체계두께 강화, 비교 우위 부각.

## 레이아웃 사양 (세로형 대비 구조)
1.  **헤드라인**: 28pt 이상 확대 적용하여 가독성 확보
2.  **좌측 영역 [제거]**: 회색 처리된 불필요 항목 나열 → 제거를 통한 비용 절감 강조
3.  **우측 영역 [강화]**: #FF4B5C로 시각 강화된 핵심 보장항목 배치 — 실질적 혜택 부각
4.  **비교 매트릭스**: 한 페이지 내 대비 구조 집약, 사용자가 즉시 비교 가능한 레이아웃
