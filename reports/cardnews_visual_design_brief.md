# 카드뉴스 시각 디자인 브리프: 보험 구조 비교

## 1. 핵심 비주얼 컨셉
- **대비형 2분할 레이아웃**: 모바일 최적화를 위해 세로형이나 정사각형형에서 좌(제거)/우(강화)를 명확히 대비시키는 단일 이미지 소스 활용
- **시각 요소 정의**:
  - 제거 항목: 회색(#808080), 삭제 아이콘 및 취소선 처리 → 불필요한 보험료 누수원인 시각적 거부 표현
  - 강화 항목: 브랜드 강조 컬러(#FF4B5C) 사용 — 핵심 보장(진단비, 수술비 등)에 대한 혜택 부각

## 2. 비교표 디자인 가이드
| 구분 | 제거 (Remove) | 강화 (Strengthen) |
| :--- | :--- | :--- |
| **시각적 처리** | 회색 (#808080) / 삭제 아이콘 적용 | 브랜드 강조 컬러 (#FF4B5c) 적용 |
| **표현 방식** | 불필요한 특약 및 중복 항목 제거 표시 | 진단·수술진료비 등 필수 보장 강화 표기 |

## 3. 주요 수치 가시화 원칙
- 중요 지표(67% 절감, 한도 상승분)는 최소 28pt 이상으로 확대하여 시선 집중 유도
- 카드뉴스 내 모든 대비 항목은 위의 두 가지 컬러 체계를 엄격히 따름

## 4. 배포 패키지 구성 요건
- 인스타그램용 세로형 레이아웃이 적용된 비교표 이미지 포함 — [최종] 보험 구조 비교 분석 보고서 내용과 일치 확인 완료
