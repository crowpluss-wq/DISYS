# [카드뉴스 디자인 브리프] 제거 vs 강화 대비 구조 (G-1234567890 통합)

## 🎨 디자인 목표
모바일 스크롤 환경에서 한눈에 극명한 시각적 대조를 이루는 세로형 2분할 카드뉴스 이미지 소스 제작. "제거"의 경제성과 "강화"의 실속을 즉시 인지시키는 것이 핵심임.

## 🎨 비주얼 시스템
- **구분 컬러:**
  - 제거(Remove): #808080 (회색) - 불필요한 비용과 중복 요소를 지워낸 상태 시각화
  - 강화(Strengthen): #FF4B5C (강조용 레드계열) - 진단·수술비 보장 극대화 강조
- **아이콘 세트:** 제거 영역에는 'X' 또는 쓰레기통 형태의 제거 아이콘 배치, 강화 영역에는 체크마크나 상승 화살표 등의 강화 아이콘 배치

## 🎨 레이아웃 사양
- **그리드:** 모바일 최적형 2분할 (세로 분할 권장) - 상/하 또는 좌/우 수직 대비 구조 적용.
- **텍스트 영역:** 각 구획의 헤더(제거 / 강화), 서브 문구, 보험료 비교표 요약 배치

## 🎨 디자인 가이드라인
- 제거 영역은 회색 배경이나 테두리(#808080)를 사용하여 '비활성화' 강조.
- 강화 영역은 선명한 대비 컬러(#FF4B5C)와 큰 사이즈의 아이콘으로 시각적 무게중심을 강화할 것.

## 🎨 레퍼런스 (Conceptual)
1. [모바일] 수직 분할형 카드뉴스 - 상/하로 나뉜 비교표 형태(참고: reports/cardnews_visual_design_brief_v3.md)
2. [비교 구조] 제거 아이콘을 포함한 '제거 vs 강화' 텍스트 대비 레이아웃 (cf. insurer report 내 대비구조)
3. [강화 표현] 강조 컬러(#FF4B5C)를 사용해 핵심 보장 내용을 강렬하게 부각시킨 비주얼

## 🎨 제안 컨셉 (3案)
- **[Option A - 클래식 분할형]:** 좌/우 수직 split을 적용한 레이아웃. 왼쪽은 회색 계열의 제거 항목, 오른쪽은 강화 컬러 기반의 핵심 보장 리스트 나열 (가독성 최적화).
- **[Option B - 상하 스크롤 대응형]:** 세로 분할 구조. 위쪽 영역에는 '불필요한 지출 제거'를 배치하고 아래쪽에 '진단·수술비 강화'를 강조 — 모바일에서 시각적 대비 극대화.
- **[Option C - 비교 매트릭스 통합형]:** 화면 중앙을 가로지르는 경계선이 있고, 양옆이나 상하의 두 영역 간 아이콘과 컬러 강도를 이용해 제거 vs 강화 구조를 표현한 레이아웃.
