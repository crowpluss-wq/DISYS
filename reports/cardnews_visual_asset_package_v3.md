# [DEPLOYMENT READY] 보험 비교 카드뉴스 시각화 디자인 가이드 (모바일 최적화 버전)

## 1. 기본 레이아웃
- **형태**: 세로형 2분할 한 페이지 구성 (비교의 직관성 극대화)
- **구조**: 좌측 [제거(Remove)] / 우측 [강화(Strengthen)] 대비 배치

## 2. 컬러 및 스타일 사양
- **제거 항목 (#808080)**: 회색 처리하여 불필요한 가입 조건임을 시각적으로 제거
- **강화 항목 (#FF4B5C)**: 진한 빨간색을 사용하여 핵심 보장 강화 부위 강조
- **삭제 아이콘**: 제거 대상 항목 옆에 삭제(x) 마크 표기

## 3. 타이포그래피 (모바일 가독성 최적화)
- **본문 및 수치**: 모든 비교 금액과 주요 수치는 최소 18pt 이상 고정 (가로 모드/세로 스크롤 시 명확한 크기 유지)
- **제목**: 강화 쪽의 제목은 강조 컬러(#FF4B5C) 적용

## 4. 대비 구조 매트릭스 가이드
| 항목 구분 | 제거(Remove) 레이아웃 처리 | 강화(Strengthen) 레이아웃 처리 |
|---|---|---|
| 불필요 특약 | 회색처리 및 삭제 아이콘 포함 | - |
| 주요 진단·수술비 등 | - | 강조 컬러 적용, 수치 18pt 이상 확대 표시

## 5. 제작 체크리스트
- [ ] 모든 비교 수치가 한눈에 들어오도록 가로/세로 여백 확보 확인
- [ ] 제거 항목(회색)과 강화 항목(빨간색) 시각적 대조성 극대화 검증
- [ ] 세로형 레이아웃 내 텍스트가 너무 길어지는 곳은 키워드로 간략화 |
