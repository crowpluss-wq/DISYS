# [카드뉴스 제작 패키지] 한눈에 비교되는 보험 구조 시각화 계획

## 🎨 비주얼 시스템 (가독성 최우선)
- **제거(REMOVE):** `#808080` 회색 처리 & 삭제 아이콘 표기 → 불필요한 약관 제거 강조
- **강화(BOOST):** `#FF4B5C` 포인트 컬러 적용 → 핵심 보장 범위 확대 시각화
- **가독성:** 모든 비교 수치 및 금액은 최소 18pt 이상 유지

## 🖼 레이아웃 컨셉 (한 페이지 분량)
세로형 2분할 대비 구조: 상단에 '불필요/중복' 요소를 회색(제거 영역), 하단에 '실무적 담보/가입 문턱 완화'를 강조 컬러(강화 영역)로 배치

## 📲 배포용 후크 (인스타그램 투 트랙)
- **[오전 - 정보형]**: "왜 내 보험료만 비싼지 아시나요? 불필요한 거품을 제거하고 핵심에 집중해야 합니다." → 카드뉴스 시각 데이터 활용
- **[오후 - 관계형]**: "당신에게 딱 맞는 옷처럼, 당신의 일상에 필요한 보장만 남겼습니다." → 강화 구조 중심
