# 카드뉴스 시각 디자인 소스 패키지 (제거 vs 강화 대비 구조)

## 1. 컬러 및 타이포그래피 가이드
- **제거(REMOVE):** `#808080` 회색 처리 및 삭제 아이콘 표기 → 불필요한 거품 제거 강조
- **강화(ENHANCE):** `#FF4B5C` 강렬한 빨간색 적용 → 실질적 보장 강화 시각화
- **모바일 가독성:** 모든 비교 수치와 금액 글꼴은 최소 18pt 이상 고정, 중요 지표는 볼드 처리

## 2. 레이아웃 구조: 세로형 2분할 카드뉴스 (One-Page)
비교 보고서의 대비 체제를 시각적 레이아웃으로 변환합니다.

| 구분 | 왼쪽 섹션 (제거 영역) | 오른쪽 섹션 (강화 영역) |
| :--- | :--- | :--- |
| **디자인** | 회색(`#808080`) / 삭제 아이콘 | 강조색(`#FF4B5C`) / 볼드체 포인트 |
| **내용** | 불필요한 특약 및 거품 제거 항목 나열 | 진단 · 수술비 등 강화된 보장 구조 |

## 3. 시각적 비교표 구성안 (2분할 대비형)
[이미지 영역] 세로를 기준으로 좌측은 회색톤의 '제거' 리스트, 우측은 강조 컬러 기반의 '강화' 리스트 배치

- **좌(GRAY):** 불필요한 특약들 → "불필요한 거품 제거" 문구와 함께 삭제 아이콘 시각화
- **우(RED):** 진단·수술비 등 핵심 보장 항목 → "#FF4B5C强化", 가독성 높은 큰 글씨 적용

## 4. 배포용 콘텐츠 패키지 (Instagram/Blog)
[모바일 최적화] 모든 수치는 최소 18pt 이상으로 유지하며 시각적 대조를 한눈에 확인 가능하도록 구성
