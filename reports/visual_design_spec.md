# 비교 분석 보고서 시각화 사양 (한 페이지 분량)

## 1. 기본 디자인 원칙
- **목표**: 복잡한 보험 상품을 한눈에 대비되게 표현하여 가입자 체감형 정보 전달
- **레이아웃**: 세로형 2분할 카드뉴스 구조 적용 (상단/하단 또는 좌/우 시각적 대조)
- **강조점**: 제거(Grey)와 강화(#FF4B5C) 대비를 명확히 하여 '맞춤형 보장' 부각

## 2. 컬러 및 타이포그래피
- **메인 강조색**: #FF4B5C (강화 항목, 핵심 수치용)
- **대비 배경색**: Grey (제거 영역 처리 - 회색이나 삭제 아이콘 활용)
- **폰트 사이즈**: 주요 비교 수치는 가독성 위해 28pt 이상 확대 적용

## 3. 콘텐츠 구성 및 배포 패키지
- **정보형(오전)**: 제거/강화 매트릭스 위주의 정보 전달용 후크 세트 사용
- **관계형(오후)**: 체감 중심의 관계성 형성용 문구와 비주얼 조합

## 4. 카드뉴스 디자인 사양 (2분할)
- **상단/좌측 영역**: 제거 대비 - 회색 처리 및 삭제 아이콘 표시로 불필요한 가입 부담 시각화
- **하단/우측 영역**: 강화 대비 - #FF4B5C 적용, 주요 혜택 수치 확대 배치
