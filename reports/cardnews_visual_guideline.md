# [시각 가이드라인] 보험 비교 카드뉴스: 제거 vs 강화 대비 구조

## 1. 레이아웃 및 디자인 원칙 (G-1234567890 통합)
- **구조**: 모바일 최적화 세로형 2분할 레이아웃 적용
- **좌측(제거)**: 회색(#808080), 삭제 아이콘, 텍스트 축소 → 불필요한 중복 제거 시각화
- **우측(강화)**: 강조 컬러(#FF4B5C), 큰 글씨체 — 핵심 진단/수술비 등 강화 포인트 부각

## 2. 컬러 및 타이포그래피 사양
| 구분 | 제원 | 비고 |
| :--- | :--- | :--- |
| **제거색** | #808080 (Gray) | 불필요한 항목 시인용 |
| **강화색** | #FF4B5C (Red/Vivid) | 핵심 보호 포인트 강조 |
| **폰트** | 28pt 본문 / 강조 타이틀 | 가독성 중심 고딕체 계열 |

## 3. 비교 매트릭스 시각적 구성 요소 (Designer용 요약)
- [제거] #808080 + 삭제 아이콘 사용
- [강화] #FF4B5C 강조 컬러 단일색 배치
