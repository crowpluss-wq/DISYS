# 보험 설계 비교 요약 보고서

## 대비 구조: 제거 vs 강화
| 구분 | 불필요한 특약 제거 (Grey) | 실질적 보장 강화 (#FF4B5C) |
|---|---|---|
| 처리 방식 | 회색 처리 및 삭제 아이콘 적용 | #FF4B5C 포인트 컬러 강조 |
| 시각 매핑 | 왼쪽 2분할 영역 / 세로형 레이아웃 | 오른쪽 2분할 영역 / 수치 확대(28pt+) |

## 한 페이지 핵심 요약
- **제거**: 불필요한 중복 특약을 제거하여 보험료 부담을 낮추고 구조를 단순화함.
- **강화**: 고객 맞춤형 보장 항목에 #FF4B5C 컬러로 시각적 포인트 부여, 실질적인 혜택 강조.

## 인스타그램 배포용 후크 세트 (5종)**
1. [09:00] "아직도 불필요한 특약으로 보험료 내고 계신가요? 제거와 강화의 극명한 대비를 한눈에 확인하세요." #보험비교 #맞춤형보장 #디시스
2. [09:00] "복잡함은 버리고 필요한 것만 채우세요. 2분할 레이아웃으로 시원하게 보여주는 보험 비교 매트릭스!"
3. [18:30] "당신의 보험, 제대로 강화되고 있나요? 제거해야 할 특약과 반드시 받아야 할 강화 항목을 한 페이지에 담았습니다."
4. [18:30] "비교할수록 좋은 보장! 회색(제거) vs 빨강(#FF4B5C강화), 시각으로 입증하는 진짜 보험 설계를 만나보세요."
5. [피크타임 공통] "한눈에 비교하고 바로 결정하세요 — 제거와 강화의 대비로 완성된 최고의 선택안을 배포합니다."

## 디자인 가이드 요약
- **제거(Remove)**: 회색 처리 + 삭제 아이콘 활용 / **강화(Enhance)**: #FF4B5C 포인트 컬러 적용
- **레이아웃**: 세로형 2분할 대비 구조 (왼쪽/오른쪽 대조)
- **가독성**: 수치 및 중요 지표는 최소 28pt 이상 확대
