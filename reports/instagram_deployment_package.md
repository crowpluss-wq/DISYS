# 인스타그램 배포 콘텐츠 패키지 (제거 vs 강화 대비 구조 기반)

## 1. 핵심 메시지 구조
- **제거(Grey)**: #808080 - 불필요한 보험 항목 및 거품을 제거하여 고객의 선택 피로도를 낮춤
- **강화(#FF4B5C)**: 진단비·수술보장 강화 모델을 시각적으로 부각

## 2. 배포 트랙별 콘텐츠 세트

### [오전] 정보형 (Information Track) - "팩트로 설득"
**후크**: "보험료 거품, 제거하고 핵심 보장만 채웠습니다."
- **문구**: 불필요한 특약을 덜어낸 자리에 진단비와 수술비를 강화했습니다. 비교 매트릭스에서 회색(제거)과 주황(#FF4B5C, 강화) 대비로 확인하세요.
- **해시태그**: #보험리뷰 #진단비강화 #불필요한특약제거 #[디시스]

### [오후] 관계형 (Relational Track) - "공감과 신뢰"
**후크**: "내 보험, 제대로 된 것 하나만 남기고 싶다면?"
- **문구**: 복잡한 특약 대신 필요한 보장에 집중하세요. 제거 포인트와 강화 포인트를 한눈에 비교해 드립니다.
- **해시태그**: #보험설계사 #맞춤형보장 #내꺼야이쁜보험

## 3. 시각 가이드 (코다리/한자이 검증용)
- 모든 수치 글꼴 최소 18pt 이상 적용 여부 확인
- 제거 포인트(#808080)와 강화포인트(#FF4B5C) 대비 명확도 체크
