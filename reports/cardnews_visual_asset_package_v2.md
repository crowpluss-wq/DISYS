# 🎨 Designer: 모바일 최적화 카드뉴스 시각 자산 패키지 (제거 vs 강화 대비)

## ✅ 디자인 컨벤션 및 사양 검증
- **시각 구조**: 세로형 2분할 레이아웃 — 왼쪽(불필요한 항목 제거), 오른쪽(맞춤형 보장 강화)
- **대비 색상**: 제거(#808080 / 그레이), 강화(#FF4B5C / 레드)
- **가독성 기준**: 모든 수치 및 금액은 모바일 가독성을 위해 최소 18pt 이상 고정 (이미 검증됨)

## 🖼️ 카드뉴스 시각 레이아웃 설계안
| 구분 | 제거 항목 (Remove) | 강화 항목 (Strengthen) | 비고 |
| :--- | :--- | :--- | :--- |
| **가입 조건** | 불필요한 중복 특약 제외 (#808080) | 개인별 맞춤형 보장 설계 강조 (#FF4B5C) | 2분할 대조 구조 |
| **수치 비교** | 제거 대상 항목 회색 처리 및 삭제 아이콘 표기 | 핵심 강화 진단비 · 수술비 한도 최대화 시각적 대비 | 모든 수치는 18pt 이상 고정 |
