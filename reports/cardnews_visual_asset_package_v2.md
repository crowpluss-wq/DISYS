# 카드뉴스 및 앱 전환 배너 디자인 가이드 (모바일 최적화)

## 비주얼 시스템
- **제거(Remove)**: `#808080` — 불필요한 비용, 중복 특약을 회색으로 처리하여 제거 강조
- **강화(Enhance)**: `#FF4B5C` — 맞춤형 보장 및 실질적 보호 강화 항목에 강렬한 레드톤 적용
- **레이아웃**: 세로형 2분할 대비 구조 (좌: 제거 / 우: 강화)

## 콘텐츠 패키지 구성
### 1. 인스타그램 카드뉴스 자산
- [ ] 비교표 이미지: `CompareMatrix` 데이터 기반의 2분할 레이아웃 시각화 소스
- [ ] 강조 문구: "불필요한 건 빼고, 진짜 필요한 것만 채웠다" (제거/강화 대비 구조 활용)

### 2. 배포용 트래킹 코드
- **코드**: `G-1234567890`
- **적용 위치**: 모든 인스타그램 게시물 링크 및 프로필 내 랜딩페이지 연결 지점 삽입
