# 제거 vs 강화 대비 구조 (카드뉴스용)

| 구분 | 기존 보험 [제거 - #808080] | 새로운 설계 [강화 - #FF4B5C] | 비고 |
| :--- | :--- | :--- | :--- |
| 진단비 한도 | 1,000만원 이하의 불필요한 소액성 항목 통합 제거 | **진단 및 수술비 집중 강화** (대형 질병 보장 확대) | 핵심 차별화 포인트 |
| 입원 일당 | 중복된/실효 없는 특약 제외 | 실제 체감 가능한 치료 중심 한도 현실화 | 가입자 체감 증대 |
| 보험료 최적화 | 제거를 통한 불필요한 거품 삭제 | **보장 강화 및 구조 개선으로 실질 비용 절감** | 핵심 메시지 유지 |

## 시각 레이아웃 지침 (세로형 2분할)
- 왼쪽: '#808080' 회색 처리된 제거 항목들 — '불필요한 거품 삭제' 강조
- 오른쪽: '#FF4B5C' 강화 컬러의 새로운 설계 — '체감하는 보장 확대' 시각화
- 모든 수치 정보는 가독성을 위해 최소 18pt 이상의 글꼴 크기로 표시

## 배포용 시각 디자인 가이드
- **제거(Grey)** vs **강화(#FF4B5C)** 대비를 통해 고객이 체감하는 보험의 질적 차이를 직관적으로 전달합니다.
- 인스타그램 채널별 두 트랙 후크 세트를 활용하여 콘텐츠 패키지를 배포하십시오.

# [최종] 카드뉴스 시각 디자인 가이드 (ko-170 규격 준수)

## 🎨 비주얼 시스템
- **제거(REMOVE):** `#808080` 회색 처리 및 삭제 아이콘 표기 → 불필요한 거품 제거 강조
- **강화(ENHANCE):** `#FF4B5C` 포인트 컬러 적용 → 실질적인 보장 강화 부각

## 🖼 레이아웃 구조: 세로형 2분할 카드뉴스
복잡한 보험 문구를 두 영역으로 분할하여 '불필요함'과 '보장 강화'의 질적 차이를 직관적으로 전달합니다.

**[왼쪽 섹션 - 제거]**
- 색상 코드: `#808080`
- 시각 효과: 중복 항목 회색 처리 및 삭제 아이콘 표기
- 메시지 방향: '거품 없는 보험' — 불필요한 특약과 소액성 진단비 통합

**[오른쪽 섹션 - 강화]**
- 색상 코드: `#FF4B5C` (강조 컬러)
- 시각 효과: 강조 포인트로 대조 구조 활용
- 메시지 방향: '체감하는 보장' — 질병 보장 확대 및 실질 비용 절감을 통한 한도 현실화

## 📱 가독성 최적화
모바일 중심 배포를 위해 모든 수치 정보의 글꼴 크기를 최소 18pt 이상으로 설정합니다.

## 📢 인스타그램 트랙별 후크(Hook) 세트
- **오전용 (정보형):** '왜 당신 보험이 부족한지' 숫자로 제시하는 비교 매트릭스 기반 문구
- **오후용 (관계형):** 실제 피해 사례와 대조되는 제거/강화의 질적 차이를 강조하는 감성 후크
