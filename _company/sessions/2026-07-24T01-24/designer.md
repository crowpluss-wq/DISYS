# 보험 비교 카드뉴스 & 앱 대비 구조 시각 가이드 (최종)

## 1. 비주얼 핵심 원칙: "제거 vs 강화"
복잡한 정보 나열을 배제하고, 회색(회피·삭제)과 레드계열(강조·선택)의 극명한 색대비로 '맞춤형 보장' 가치를 단숨에 인식시킵니다.

## 2. 컬러 시스템 (Hex Code 기반)
- **제거 영역 (Remove):** `#808080` — 불필요 특약, 중복 항목을 회색처리하여 시각적 소거 처리.
- **강화/선택 (Enhance):** `#FF4B5C` — 핵심 혜택 및 앱 전환 유도 포인트에 적용되는 강렬한 레드계열.

## 3. 비교표 디자인 레이아웃 (2분할 카드뉴스형)
모바일 가독성을 최우선으로 세로/수평 대비 구조를 사용합니다:

| 구분 | 제거 영역 (#808080) | 강화/선택 영역 (#FF4B5C) |
| :--- | :--- | :--- |
| **레이아웃 위치** | 좌측 (또는 상단 1분할) | 우측 (또는 하단 2분할) |
| **시각 처리** | 중복 항목 삭제, 제거 아이콘 배치 | 핵심 문구 강조, 앱 전환 화살표 추가 |
