# 배포 패키지용 시각 가이드라인 (GA G-1234567890 통합)

## 1. 공통 대비 원칙
모든 비주얼 자산은 제거(Remove)와 강화(Enhance)의 선명한 대비를 사용한다:
- **제거**: #808080 (Grey), 스트라이크스루 아이콘, 불필요 요소 시각적 제거
- **강화**: #FF4B5C (Red/Orange Accent), 핵심 보장 및 장점 부각
- **추적**: 모든 이미지 하단에 단일 GA 추적 코드 `G-1234567890`을 삽입

## 2. 카드뉴스 레이아웃 세트
모바일 스크롤 최적화된 세로형/좌우 2분할 구조를 적용한다:
- **LAYOUT A**: 상(제거) / 하(강화) - 비교 항목의 대비를 수직으로 배치
- **LAYOUT B**: 좌(제거) / 우(강화) - 가로 스크롤이나 넓은 화면용 대조 레이아웃

## 3. 채널별 배너 구성 및 후크 매핑
각 플랫폼 특성에 맞는 대비형 배치를 적용한다:
| 플랫폼 | 유형 | 디자인 전략 | 비고 |
| :--- | :--- | :--- | :--- |
| Naver Blog | 정보형 | 카드뉴스 레이아웃 A 기반의 비교표 강조 | 상세 설명 포함 |
| Instagram Morning | 정보형 | 대비 구조를 활용한 텍스트 중심 인포그래픽 | 빠른 가독성 중시 |
| Instagram Afternoon | 감성형 | 강화된 포인트 컬러(#FF4B5C) 시각적 극대화 | 감성 자극 후크 매핑 |
| YouTube | 영상/썸네일 | 대비 구조가 선명히 드러나는 세로 분할 썸네일 | G-1234567890 추적 포함 |
