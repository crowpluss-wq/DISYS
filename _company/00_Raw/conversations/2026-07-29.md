import os
import json


def verify(package_dir):
    manifest = json.loads(open(os.path.join(package_dir, 'manifest.json')).read())
    tracking_id = manifest['tracking_id']
    files = [asset['path'] for asset in manifest['assets']]

    # 1. 트래킹 코드 중복 검사 (G-1234567890)
    all_content = ""
    for f in files:
        with open(f, 'r') as file:
            all_content += file.read()

    if all_content.count(tracking_id) != 1:
        raise ValueError("중복된 트래킹 코드 발견!")

    # 2. 경로 정상성 검사
    for f in files:
        if not os.path.exists(f):
            raise FileNotFoundError(f"파일이 존재하지 않음: {f}")


def main():
    verify('deploy_package')
    print("배포 패키지 무결성 검증 완료.")


if __name__ == '__main__':

# [분석 보고서] 불필요한 특약 제거와 핵심 보장 강화가 만드는 '맞춤형 보험 설계'의 힘

## 1. 분석 개요: 왜 ‘제거’하고 ‘강화’하는가?
보험을 고를 때 가장 큰 고민은 두 가지입니다. **"내가 내지도 모르는 불필요한 특약에 돈을 쓰는 것은 아닌가?"**와 **"막상 필요할 때 제대로 보장받지 못하면 어쩌나?"**

우리는 이 두 문제를 한꺼번에 해결하는 비교 구조를 제안합니다:
- **제거(#808080)**: 가입자의 비용 부담을 높이는 중복·과잉 특약 삭제
- **강화(#FF4B5C)**: 실질적인 청구 가능성이 높은 핵심 진단 범위 및 보장 강화

| 구분 | 한화손해보험 (비교 기준) | 타 보험사 종합 비교 | 제거 (#808080) | 강화 (#FF4B5C) |
| :--- | :--- | :--- | :--- | :--- |
| **실손의료보험** | 높은 진단비 한도, 넓은 가입 범위 | 대부분 유사한 기본 구조 유지 | 불필요 중복 특약 제거 | 실질적 보장 강화로 차별화 |
| **암진단보장** | 높은 진단비, 다양한 암 분류 포함 | 보험사별 세부 설계 상이함 | 가입자용 부가 옵션 제거 | 필수 진단 범위 집중 강화 |

## 3. 한화보험 사례를 통한 강점 및 약점 분석
한화의 기존 구조는 보편적이라 우리에게 강력한 경쟁자가 되지 못합니다. 우리의 핵심 전략은 바로 **빈틈을 채우는 것**에 있습니다.

- **장점**: 불필요한 지출 요인을 걷어내고 그 비용을 진정 필요한 암·실손 강화 항목으로 재배치했습니다. 가입자는 더 정확하고 넓은 보장을 받으며, 보험사는 명확한 강점을 확보합니다.
- **단점**: 세밀화된 특약들이 일부 제거되어 기본형에서는 범용적인 성격이 유지되므로 매우 예리한 커스터마이징을 원할 시 추가 설계가 필요합니다.

## 4. 결론: 당신에게 가장 적합한 보험의 모습
결국 좋은 보험은 **'더 넓게 보장받고 더 정확하게 지불하는 구조'**에 있습니다. 불필요함을 걷어낸 자리에 실질적인 강화의 가치를 채우십시오 — 그것이 우리가 제안하는 최적 설계이며, 바로 당신을 위한 가장 안전한 선택입니다.
