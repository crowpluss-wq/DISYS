# 카드뉴스 레이아웃 사양 및 시각 가이드라인 (제거 vs 강화)

## 1. 비주얼 시스템
- **강조 컬러 (#FF4B5C):** '실질적 보장 강화' 영역에 사용 — 강렬한 레드 계열로 핵심 메시지 부각
- **제거 컬러 (Grey / #A9A9A9):** '불필요한 특약 제거' 영역에 사용 — 흐릿하게 처리하여 불필요함 시각화
- **아이콘:** 제거 항목에는 삭제 아이콘(X 표시)을 배치하여 중단 의도 명시

## 2. 레이아웃 사양 (세로형 2분할)
캔버스를 세로 방향으로 양분하며, 왼쪽과 오른쪽의 대비를 통해 직관적인 메시지 전달 — **[왼쪽]** 불필요한 특약 제거 / **[오른쪽]** 실질적 보장 강화

- **타이포그래피:** 수치는 28pt 이상 확대하여 모바일 가독성 극대화
- **카드뉴스 소스 활용**: 세로형 레이아웃과 대비 구조를 한데 통합한 단일 제작 사양을 제공함 — [enhanced_comparison_matrix_layout.md]의 디자인 결정을 계승

## 3. 시각 매핑 정보 (제거 vs 강화)
- **비교 표:** 두 분야의 항목들을 대조하는 테이블 레이아웃 적용
- **색상 대비 활용**: 제거 항목(Grey), 강화 항목(#FF4B5C)으로 명확하게 구분하여 직관적 가독성 확보

## 4. 제작 가이드라인 (제작용 에이전트 전달용)
1. 한 페이지 분량의 카드뉴스 소스를 세로형 2분할 레이아웃으로 구현하십시오
2. 제거 영역을 Grey와 삭제 아이콘으로 처리하고, 강화 영역은 #FF4B5C 컬러를 사용하십시오
3. 중요 수치를 크게 키우고 대비 구조가 시각적으로 명확히 드러나도록 배치하십시오
