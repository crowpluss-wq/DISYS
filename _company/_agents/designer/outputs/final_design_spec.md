# [최종] 비교 매트릭스 시각 강화 및 카드뉴스 제작 사양

## 1. 컬러 팔레트 (Color Palette)
- **제거(Remove)**: Grey (#A9A9A9) - 불필요한 특약, 제외 항목에 적용
- **강화(Strengthen)**: #FF4B5C - 핵심 보장, 비교 우위 구간 강조용 메인 컬러

## 2. 레이아웃 구조 (Layout Structure)
- **비교 매트릭스**: 세로형 2분할 대비 구조 사용
  - 왼쪽: 제거(Grey 처리 및 삭제 아이콘)
  - 오른쪽: 강화(#FF4B5C 적용, 28pt 이상 확대 수치 표시)

## 3. 카드뉴스 디자인 사양 (Cardnews Spec)
| 요소 | 상세 내역 | 비고 |
|---|---|---|
| 배경색 | 무채색/흰색 기반 대비 극대화 | 시각적 명확성 우선 |
| 타이포그래피 | 강조 수치는 28pt 이상 확대, 고정 폭 활용 | 가독성 확보 |
| 아이콘 | 제거 항목에 Strike-through 및 X 마크 표기 | 즉각적 인지용 |

## 4. 코다리(개발) 전달 사항
- `enhanced_comparison_matrix_layout.md`의 테이블 레이아웃을 위 대비 구조로 렌더링할 것
- 비교표에서 제거 항목은 비활성 처리, 강화 항목만 하이라이트 적용

## 5. 영숙(배포/콘텐츠) 전달 사항
- 인스타그램 후크 5종과 결합하여 배포 패키지로 활용
- 카드뉴스 이미지 생성 시 #FF4B5C 대비를 메인 비주얼로 사용

## 6. 디자인 가이드 (Design Guide)
- **비교 구조**: 2분할 레이아웃 — 왼쪽 '불필요한 특약 제거', 오른쪽 '실질적 보장 강화'
- **시각 강조**: 제거 영역(Grey)과 강화 컬러(#FF4B5C)의 명도/채도 대비를 활용해 한눈에 들어오는 비교표 제작

- 인스타그램용 세로형 2분할 레이아웃 및 비교표 디자인 최종 배포 패키지 통합 완료

배포 패키지가 완성되었으므로, 영숙에게는 채널별 가이드를 적용한 배포 준비를, 코다리에게는 시각화된 카드뉴스를 활용한 보고서 레이아웃을 마지막으로 할당하고 본 디자인 작업은 마칩니다.
