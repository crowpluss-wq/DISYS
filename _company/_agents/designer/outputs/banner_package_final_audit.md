# 배포용 이미지 소스 패키지 (최종)

## 1. 시각적 대비 구조 사양
- 제거 영역: #808080 회색 처리 / 삭제 아이콘 병기 → 불필요한 지출 제거 강조
- 강화 영역: #FF4B5C 강렬한 레드 사용 · 핵심 보장 가치 시각적 부각
- 수치 표기: 모든 비교 수치는 최소 28pt 이상으로 확대 → 모바일/웹에서 즉시 인지 가능

## 2. 트래킹 코드 통합 (G-1234567890)
- 각 배너 시안 하단 또는 가이드라인 내에 [Tracking ID: G-1234567890] 명시 → 광고 추적성 확보
- 코다리 검증 완료 사항 반영

## 3. 채널별 최적화 배치 (코다리/레오 협업 결과)
쇼츠(자극형 후크), 인스타그램(신뢰형 후크) 등 모든 유입 경로에서 동일한 대비 구조와 트래킹 정보가 일관되게 노출되는 통합 패키지 구성.
