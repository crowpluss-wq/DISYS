# 카드뉴스 배포용 이미지 소스 및 디자인 가이드 (G-1234567890 통합)

## 1. 시각 구조 정의 (모바일 최적화 세로형 2분할)
- 제거(Remove) 영역: 배경색 #808080, 회색 처리/삭제 아이콘 사용. 불필요한 비용과 중복 특약의 삭제를 강조한다.
- 강화(Enhance) 영역: 배경색 #FF4B5C 강렬한 대비 색상 적용. 핵심 보장 항목을 시각적으로 부각시킨다.
- 공통 사항: 비교 수치는 최소 28pt 이상으로 확대 처리하여 가독성을 확보하고, 모든 이미지 하단에 트래킹 코드 G-1234567890를 포함한다.

## 2. 디자인 사양 (Designer/데모퍼레이터용)
- 레이아웃: 세로형 2분할(상/하 또는 좌/우). 모바일 스크롤 환경에서 한눈에 대비가 들어오도록 설계.
- 아이콘 및 그래픽 요소: 제거 영역에는 삭제를 의미하는 회색 처리된 아이콘, 강화 영역에는 보호의 강화를 나타내는 시각적 요소를 배치한다.

## 3. 마케팅 콘텐츠 (인스타 에이전트용)
- 채널 대응형 후크 세트(5종): 각 인스턴트 유입 경로에 최적화된 문구로 구성하며, 트래킹 코드를 포함한 배포 패키지에 통합한다.

## 4. 검증 상태
- 제거/강화 대비 구조와 디자인 가이드는 보고서 내용과 시각적으로 일치함을 재검증 완료함.
