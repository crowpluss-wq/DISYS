# [보고서] 불필요한 특약을 덜어내고 맞춤형 보장을 강화했습니다
## 비교 분석표
- 기존 대안: 중복된 특약이 포함되어 있어 실속이 낮음 (회색 처리)
- 우리 설계: 불필요한 것은 제거하고 핵심에 집중하여 보험료 최적화

# 카드뉴스 대비 구조
1. 2분할 레이아웃을 사용하며, 한쪽은 '제거(Remove)' 아이콘으로 중복 특약을 표시
2. 다른 쪽에는 강화된 맞춤형 보장 세트를 배치 (대조적 시각화)
3. 핵심 메시지: "더이상 불필요한 것은 덜어내고 꼭 필요한 것만 채우는 설계"

## 인스타그램용 홍보 후크 5세트
1. 내 보험에 들어있는 중복 특약의 정체 — 한눈에 비교하고 필요 없는 건 제거하세요.
2. 불필요한 거 빼면 비용도 내려갑니다 - 맞춤형 보장으로 최적화된 설계 제안드립니다.
3. 복잡함은 버리고 진심만 담았다 — 15년 노하우로 완성한 맞춤형 보험 비교표 공개!
4. 당신을 위한 것 아닌 가짜 특약들 — 제거할 곳과 강화해야 할 보장을 대비했습니다.
5. 진짜 좋은 보험의 첫 단추는 '덜어내기' 부터 — 한눈에 보는 두 갈래 대조 구조
