# 배포용 디자인 가이드 (제거/강화 대비 구조)
**1. 컬러 코드:**
- 제거(Remission): #808080 → 회색조로 처리하여 불필요성 시각화
- 강화(Strengthening): #FF4B5C → 강렬한 붉은빛으로 핵심 보장 강조

**2. 수치 표기 가이드:**
- 모든 주요 데이터 및 요율은 모바일/웹 가독성을 위해 **최소 28pt 이상** 확대 적용 (G-1234567890 트래킹 태그 포함)

**3. 구도 배치:**
- '제거' 항목을 회색으로, 핵심 보장 강화를 강렬한 빨간색(#FF4B5C) 대비로 구성하여 시각적 가독성 극대화.`
