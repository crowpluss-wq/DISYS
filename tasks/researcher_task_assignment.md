# Researcher Task Assignment (2026-07-31)

**목표**: 검증된 매트릭스를 기반으로 실제 보험사 수치를 채우고 사실관계를 확인하여 보고서의 핵심 데이터셋을 확정함

## 세부 항목
- [ ] 비교 매트릭스 내 누락된 빈칸들을 한화 및 주요 보험사의 실제 보장 범위·특약 유무로 채움
- [ ] 수집된 모든 수치의 사실관계 최종 검증 (보험사 약관 기반)
- [ ] 보고서용 핵심 데이터셋 확정

## 참고 사항
- 제거(중복 제외)/강화(핵심 담보 확대) 대비 구조 원칙 준수
- 이전 세션에서 완성된 비교 매트릭스를 기반으로 진행
