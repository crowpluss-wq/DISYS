# 오늘의 핵심 작업: 보험 비교 보고서 -> 앱 트래픽 집중 패키지 구축 (최근의 모든 채널을 하나로 묶는 랜딩페이지와 배너)

## 개요
* **목표:** 인스타·블로그에서 들어온 유입이 파편적으로 소모되지 않고 '내보험다보아' 앱으로 단일하게 집중되도록 경로 통합.
* **핵심 결과물:** 앱 전환용 랜딩페이지 시각화(디자이너), 트래킹 코드 전파 및 중복 방지 배포 (코다리)

## 계획
- [ ] 코다리: 최근 생성된 모든 비교 보고서 관련 콘텐츠를 수집해 앱으로의 단일 진입 경로가 명확한지 검토. 없다면 랜딩페이지로 연결하는 중앙 집중 구조 설계(single landing page to rule them all). 트래킹 코드 전수 삽입 및 중복 배포 방지 확인.
- [ ] 디자이너: 비교 데이터 시각화를 통해 앱으로 전환해야 하는 이유가 한눈에 들어오는 갤러리형 랜딩페이지와 인스타·블로그용 앱 유도 배너 6종 제작.

## 제약 사항 (이미 결정된 것 반영)
- 디자인은 모바일 가독성 최우선(기존 결정).
- 코다리는 유사 트래킹 코드 중복이 생기지 않도록 이미 배치된 위치들 확인하며 작업할 것.
