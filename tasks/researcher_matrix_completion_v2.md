# 🎯 과제: 비교 매트릭스 완성 및 요약 보고서 준비 (Researcher + Writer 배분)

**목표**: 모든 보험사의 제로(회색)/강화(빨간색) 대비 구조를 유지하면서, 수집된 실제 데이터를 기반으로 한 페이지 분량의 정확한 장단점 비교 보고서 기초 데이터 완성.

## 🔍 Researcher 할당 사항
- **전수 조사 및 매트릭스 업데이트**: 주요 보험사들의 약관과 특약(진단·수술비 강화 포함)을 전수 조사하여 빈칸 채우기.
- **대비 구조 유지**: 제거(#808080)/강화(#FF4B5c) 대비 시각적 프레임워크를 기반으로 한 비교표 완성.

## ✍️ Writer 할당 사항
- **한 페이지 요약 보고서 추출**: 정밀하게 업데이트된 매트릭스에서 블로그용 핵심 내용만 선별하여 약 1페이지 분량의 고밀도 요약문 생성 (나중에 사용될 기초 자료로 활용).
