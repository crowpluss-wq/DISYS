# 🔍 Researcher: 보험 비교 보고서 및 인스타그램 패키지 구성 작업

## 목표
CEO 지시사항(제거 vs 강화 대비 구조 적용, 오전/오후 두 트랙 후크 포함)을 반영한 최종 비교 보고서와 인스타그램 배포 세트를 하나의 파일에 통합.

## 작업 분할 (Work Breakdown)

### 1단계: 비교 매트릭스 데이터 보강
- 대상 파일: `reports/insurance_comparison_matrix_final.md` 및 `researcher_analysis_v2.md`
- 할 일: 아직 채워지지 않은 빈칸들에 실제 수집된 보험사별 특약, 가입 조건 등 정량적 데이터를 입력하여 데이터 정확성 확보 (한화 대비 구조 유지).

### 2단계: 제거/강화 대비 구조 기반 비교 보고서 작성
- 대상 파일: `reports/comparison_report.md` (신규 생성)
- 할 일: 기존의 '제거(#808080)'(불필요·중복 특약 제외→보험료 최적화)와 '강화(#FF4B5C)'(핵심 가치 강화) 대비 구조를 시각/텍스트로 명확히 비교한 보고서 원고 완성.

### 3단계: 인스타그램 배포 세트 통합
- 대상 파일: `reports/instagram_deployment_package.md` (신규 생성)
- 할 일: 검증된 두 트랙 후크(오전 정보형 / 오후 관계형), 해시태그 및 채널별 문구를 하나로 묶어 인스타그램용 배포 패키지 구성

## 협업 계획
- **제1단계**를 [Researcher]가 수행하며 비교 매트릭스를 완성시킨다.
- **제2단계**와 **제3단계**는 한꺼번에 세션을 이어받아 [Designer/Instagram 에이전트] 등에게 분배하여 병렬이나 순차적으로 진행한다.
