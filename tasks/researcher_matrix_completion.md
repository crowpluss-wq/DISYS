## 🔍 Researcher Task: 비교 매트릭스 빈칸 데이터 보강 및 검증

**목표:** 한화 대비 구조(제거-gray / 강화-#FF4B5C)가 반영된 기초 자료 수집을 위해 비어있는 모든 보험사 항목의 실제 데이터를 채우고 사실관계를 확인한다.

### 작업 내역
1. **데이터 갱신**: 비교 매트릭스에서 아직 채워지지 않은 빈칸들을 각 보험사의 최신 약관, 보장 범위로 대체.
2. **사실 관계 검증**: 불명확한 특약이나 가입 조건은 인터넷/홈페이지를 통해 교차 확인 후 보고서 근거에 반영.
3. **대비 구조 매핑**: 제거(gray) 항목과 강화(#FF4B5C) 항목을 명확히 구분하고 비교표 완성.
