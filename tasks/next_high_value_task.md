# 🎯 다음 가치 있는 작업: 비교 매트릭스 데이터 완전성 확보

## 목표
비교 매트린의 빈칸을 실제 수집된 보험사별 특약 및 보장 범위로 채워 정확한 대조표를 완성한다. 이는 Designer가 제거(#808080)/강화(#FF4B5c) 대비 구조를 시각화하는 데 필요한 정밀 데이터를 제공함.

## 할당
- **Researcher**: 불명확하거나 확인이 필요한 정보(제도, 약관 등)는 인터넷을 통해 사실 관계를 정확히 조사하고 수치를 업데이트한다.
- **Designer** (대기): Researcher가 데이터 세트를 완성하면 비교표의 시각 가이드라인 및 강화 포인트 28pt 확대 규칙을 적용하여 최종 카드뉴스 레이아웃 생성

## 참고 사항
메모리에 유사한 항목이 여러 개 있으므로, 이번 작업은 '데이터 정확성'과 '비교 표 완성'이라는 구체적인 결과물에 집중하며 다른 일반적 조사들과 중복되지 않도록 한다.
