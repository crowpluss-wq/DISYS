## Designer Task: 카드뉴스 디자인 및 시각 요소 최종 구성
이미 검증된 한 페이지 분량의 보험 비교 보고서를 기반으로 두 가지 형태의 카드뉴스 제작을 요청합니다.

### 공통 사양 (엄수 필수)
- 모든 수치와 금액은 가독성을 위해 최소 18pt 이상으로 유지할 것
- 제거 대상 항목: 회색 (#808080) 적용
- 강화 포인트(진단비·수술비): 진한 빨간색 (#FF4B5C) 강조

### 제작 요청 사항
[PART 1] 한 페이지 분량 비교표 카드뉴스
- [removed_vs_strengthened.md](reports/business_feasibility_analysis.md) 구조를 활용해 제거(#808080)와 강화(#FF4B5C) 대비가 시각적으로 즉시 인지되도록 구성할 것

[PART 2] 두 트랙 후크 이미지
- 오전 정보형: "당신의 보험이 진짜 진단비와 수술진료비를 지켜주고 있습니까? ..." 문구 포함
- 오후 관계형: "아는 사람들은 다 압니다, 보험은 가입할 때보다 나중에 쓸 수 있을때 제대로 된 게 중요한거..." 문구 포함

제작 완료 시 deployment_ready 태그를 부여한 뒤 세션 종료.
