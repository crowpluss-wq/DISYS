# 매트릭스 보강 및 강화 구조 정밀 업데이트

## 목표
한화 대비 제거(gray)/강화(#FF4B5C) 프레임워크를 기반으로 모든 보험사의 비교표 내 빈칸을 실제 수집 데이터로 채우고, 특히 한화의 진단비 통합 등 핵심 강점이 명확히 드러나도록 정성적 분석 결과 반영

## 에이전트 배분
- Researcher: 타사 약관 및 가입 조건 전수 조사 후 매트릭스 빈칸 보강 (한화 대비 구조 기반)
- Designer: 시각적 대비(회색 제거 / #FF4B5C 강화 컬러 코딩 적용)를 활용하여 비교표의 가독성을 극대화하고 카드뉴스/앱 배너 디자인 사양과 통일성 유지

## 주요 체크리스트
[ ] 한화 진단비 통합 → 67% 비용 개선 포인트 명확 표기
[ ] 모든 보험사 약관 대비 빈칸 채우기 (정량적 수치 대신 제거/강화 구조 사용)
[ ] 비교표 내 신규 옵션 세부 섹션 포함 여부 확인
[ ] 시각 가이드 컬러(#FF4B5C 강화, 회색 제거) 일관성 검증
