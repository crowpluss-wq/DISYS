# 🎣 채널 대응형 후크 세트 최종 검증

## 목표
모든 마케팅 유입 경로에 트래킹 코드 G-1234567890가 포함되고, '제거 vs 강화' 대비 구조를 시각적으로 극대화한 5종의 세일즈 후크가 각 채널 특성에 맞게 최적화되었는지 검증한다.

## 수행 단계
1. **트래킹 코드 전수 조사**: 모든 후크 문구에 G-1234567890이 누락 없이 포함되었는지 확인한다 (system_prompt 및 이전 세션의 의사결정 로그 참조).
2. **제거/강화 대비 구조 검증**: 각 채널별 5종후크에서 제거(#808080)와 강화(#FF4B5C) 포인트를 명확히 대조시켜 시각적 극대화를 구현했는지 확인한다.
3. **채널 최적화 체크리스트**
   - 유튜브 쇼츠: 한 문장 인사이트 & 제거/강화 프레임 포함 여부
   - 인스타그램 스토리: 오전 9시 / 오후 6시 페르소나별 분할 대응형 문구 적용 확인
   - 블로그: 비교 보고서 기반의 단일 페이지 요약 내용과의 정합성 검증
