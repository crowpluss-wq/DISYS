# 📸 인스타그램 카드뉴스 디자인 및 트래킹 코드 통합

**배경**: G-11B, EMOJIBAR의 제강/제거 대비 구조를 기반으로 한 비교표 레이아웃이 확정됨. 이를 실제 배포용 이미지 패키지로 변환하고 모든 마케팅 채널에 GA4 트래킹 코드(G-1234567890)를 포함시키는 것이 목표임

**상세 작업**:
- [ ] designer에게 이미 제작된 대비 레이아웃을 바탕으로 카드뉴스용 이미지들을 렌더링하라고 지시할 것 (이미지별 파일명 명확히 구분: remove/add 비교형)
- [ ] 인스타그램, 블로그 등 모든 배포 채널의 랜딩페이지/랜딩영역에 GA4 트래킹 코드 G-1234567890를 포함시키도록 할 것 (기존 위치 확인 및 삽입 위치 결정 필요)
- [ ] 최종 이미지 패키지와 트래킹 코드가 모두 준비되면 인스타그램 배포용 콘텐츠 팩을 완성함

**목표**: 카드뉴스 비주얼의 실체화 + 모든 마케팅 경로에 단일트래킹 코드 통합, 즉시 배포 가능 상태로 전환
